# Contributing to The Internship Hub

Thanks for helping keep this the best single map to tech-internship resources! 🎯

## What belongs here

A resource is a good fit if it's **all three**:

1. **Free & open source** (or a free, no-paywall tool/site).
2. **Actively maintained** — updated within the last ~6 months — *or* an evergreen classic (e.g. Jake's Resume, system-design-primer).
3. **Genuinely useful** — something you'd recommend to a friend job-hunting.

We generally **don't** add: paid courses, referral-farming links, dead/abandoned repos, or duplicates of what's already listed.

## How to add a resource

1. **Fork** this repo and create a branch.
2. Find the **right section** in `README.md`.
3. Add your entry **in the existing table/list format**, with a **one-line description of why it's worth someone's time**.
4. Keep links alphabetical or by relevance within a section where it makes sense.
5. Open a **Pull Request** with a short note on what you added and why.

## Quality bar for descriptions

- ✅ "Auto-scraped internships from 4,300+ boards with visa-sponsorship flags."
- ❌ "Good repo for jobs."

Be specific about *what it covers* and *who it's for*.

## Reporting a dead or outdated link

Open an **Issue** (or a PR) noting the broken link — that's a hugely valuable contribution too.

## Code of conduct

Be kind, be patient, assume good faith. This is a resource by job-seekers, for job-seekers.

Happy contributing — and good luck landing that offer! 🚀
